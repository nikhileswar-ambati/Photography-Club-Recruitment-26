# 📸 Photography Club Landing Page

A responsive landing page for a **Photography Club website** designed to showcase the club, its events, and photography gallery.  
The page provides a modern and visually appealing interface that works across **mobile, tablet, and desktop devices**.

---

## 🌐 Live Demo

https://photography-club-recruitment-26.vercel.app/


---

## 🚀 Project Description

This project focuses on building a **responsive landing page** for a Photography Club.  
It includes key sections such as navigation, hero banner, about information, events, and gallery preview.

The goal of the project is to practice **responsive web design using HTML, CSS, and modern layout techniques like Flexbox and Grid**.

---

## ✨ Features

- Responsive **Navigation Bar**
- Attractive **Hero Section**
- Informative **About Section**
- **Events Section** showcasing photography activities
- **Gallery Preview** with responsive image grid
- Mobile-friendly design
- Clean and modern UI

---

## 🧩 Website Sections

### 🧭 Navigation Bar
Includes links for easy navigation:

- Home
- About
- Gallery
- Events
- Contact

---

### 🎯 Hero Section

The hero section contains:

- Main heading
- Short description about the photography club
- Call-to-action button (Join / Explore Gallery)

---

### 📖 About Section

Provides information about the Photography Club such as:

- Club mission
- Activities and goals
- Opportunities for students interested in photography

---

### 📅 Events Section

Displays photography related events such as:

- 📷 Photo Walk
- 🎓 Photography Workshop
- 🖼️ Photo Exhibition

Each event highlights photography learning and collaboration opportunities.

---

### 🖼️ Gallery Preview

A responsive image gallery displaying sample photos using a **grid layout**.

Features:

- Responsive image grid
- Clean photo layout
- Works across different screen sizes

---

## 📱 Responsive Design

The website is designed to work smoothly on:

- 📱 Mobile Devices
- 📲 Tablets
- 💻 Desktop Screens

Responsive design is implemented using:

- Flexbox
- CSS Grid
- Media Queries
